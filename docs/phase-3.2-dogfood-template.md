# Phase 3.2 蘇菲試用紀錄模板（dogfood log）

> 用法：Phase 3.2 demo 跑通後、Edward 開始日常用蘇菲講話
> 每次 session 結束、把當下感覺 / 卡點 / 想改的東西寫進來
> 累積 1 週 = 整理出 Phase 3.3 改進清單

---

## 試用 Session 紀錄

每次新一段對話、複製下面這段填：

```
### {{日期 + 時段}} · {{場景描述}}

- 持續時間：{{X 分鐘}}
- 場景：{{書房 / 通勤 / 廚房 / 開車 / 深夜 / 早晨...}}
- 主題：{{工作 / 情緒 / 規劃 / 隨意聊...}}

**對話自然度**（1-5 · 5 最自然）：
- 嘴型對得起聲音嗎？{{X / 5}}
- 表情自然嗎？不過於僵硬？{{X / 5}}
- 反應延遲怎樣（< 1 秒 / 1-2 秒 / > 2 秒）：
- 蘇菲講話 tone 是不是你想要的？{{X / 5}}

**真人感**（1-5）：
- 第一秒看下去、像不像跟真人視訊？{{X / 5}}
- 中間有沒有「uncanny valley」恐怖谷感？{{有 / 沒有}}
- 你會不會自然繼續講話、忘記她是 AI？{{會 / 不會}}

**家人試**（如有 Qiana 加入）：
- Qiana 第一秒反應：
- 她聽得進去蘇菲講的話嗎？
- 有沒有讓她不舒服 / 怕的瞬間？
- 旁邊有人看到 / 聽到：{{沒有 / 有 · 對方看到什麼 · 說了什麼}}
  - ⚠ 旁邊的人不主動跟蘇菲互動、不錄他們聲音樣本（基本隱私）

**卡點 / 不滿意的地方**：
- {{列出 3-5 個具體的}}

**想改的東西**：
- {{列出對應 3-5 個改進方向}}

**這次最讓你 wow 的瞬間**：
- {{1 句具體描述}}
```

## 邊界規則（dogfood 期間也守）

- ✅ Edward 自己樣本 OK（你錄你自己的聲音）
- ✅ Qiana 自願試 OK（她親口 informed consent）
- ⚠ 真有未成年互動場景出現時、回頭以真實需求重做安全機制（v0.3.0 移除過去基於錯誤前提的 hard rule）
- ❌ 不對外公開生成的 clip（除非 Track B 重審）
- ❌ 不上中國雲（仍 Modal 美國伺服器）
- ✅ 生成的 MP4 存本機 only（castle-voice-engine 機器內、不雲端同步）
