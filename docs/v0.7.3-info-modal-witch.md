## § 1 · 位置決策（C 提案 · 整合進 watermark）

**結論：右下 `.watermark` 整體點開觸發 modal**——不是新增獨立 icon、把現有 `✦ Sophie · AI Companion` 那塊變成可點。

反 A（不放右上名字旁）：
- 蘇菲名（Georgia italic 19px serif）是視覺主錨、加 ⓘ 破壞字塊純淨度
- 「身份識別 → 版本資訊」cognitive jump 浪費

反 B（不放 Start 鈕旁）：
- Start 鈕是 CTA 重點、加小 ⓘ 搶 attention
- in-call 時 Start 鈕消失、ⓘ 跟著消失 → 通話中沒入口

C 優勢：
- watermark 本就是「品牌 + 版本」概念載體
- 永遠在（idle + in-call 兩狀態都顯示）
- ✦ 星形已暗示「點我有東西」
- 彈窗從 watermark 上方冒出 = mental model 對齊

## § 4 · Dismiss 邏輯（JS · IIFE 包起來不污染全局）

```js
(function () {
  var trigger = document.getElementById("versionTrigger");
  var modal   = document.getElementById("versionModal");
  var backdrop = document.getElementById("versionModalBackdrop");
  var closeBtn = document.getElementById("versionModalClose");
  var panel   = modal.querySelector(".version-modal-panel");
  var lastFocused = null;

  function openModal() {
    lastFocused = document.activeElement;
    modal.classList.add("open");
    modal.setAttribute("aria-hidden", "false");
    trigger.setAttribute("aria-expanded", "true");
    setTimeout(function () { closeBtn.focus(); }, 50);
    document.body.style.overflow = "hidden";
  }

  function closeModal() {
    modal.classList.remove("open");
    modal.setAttribute("aria-hidden", "true");
    trigger.setAttribute("aria-expanded", "false");
    document.body.style.overflow = "";
    if (lastFocused && lastFocused.focus) lastFocused.focus();
  }

  trigger.addEventListener("click", openModal);
  closeBtn.addEventListener("click", closeModal);
  backdrop.addEventListener("click", closeModal);
  panel.addEventListener("click", function (e) { e.stopPropagation(); });

  document.addEventListener("keydown", function (e) {
    if (e.key === "Escape" && modal.classList.contains("open")) {
      e.stopPropagation();
      closeModal();
    }
  });
})();
```

ESC 雙綁注意：modal 開啟時 ESC 只關 modal、不結束通話（stopPropagation 阻 bubble）。
