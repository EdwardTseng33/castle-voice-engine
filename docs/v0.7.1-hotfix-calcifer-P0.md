## § 1 「聽不到蘇菲講話」 Root Cause（Chrome MCP 證據）

### 1.1 Diagnostic 流程

用 Chrome MCP 直接連 prod demo URL navigator.mediaDevices.getUserMedia stub 成 AudioContext OscillatorNode 假 mic stream 走完整 startConversation 流程 抓 console log。

**v0.7b 原版 fake-conversation log 證據**:

```
[sophie] user media OK
[sophie] offer created (sdp len=1632)
[sophie] ontrack kind=audio streams=1     <- ontrack 觸發 OK
[sophie] SDP exchange OK (answer len=1679)
[sophie] dc open 注入 turn_detection
[sophie] OAI evt: session.created          <- session 建立 OK
[sophie] OAI error: missing_required_parameter session.type
[sophie] ERR: OpenAI: Missing required parameter session.type
```

### 1.2 三層 Root Cause

OpenAI Realtime API GA 規範變更 2026 Q1 release Phase 7b 開發時用的是 5/22 schema 已過時 1 天:

**Layer 1**: session.update 必含 session.type=realtime v0.7b 沒帶 走出第一個 session.created 後 session.update 被拒 persona instructions 沒注入

**Layer 2**: turn_detection 從 session top-level 搬到 session.audio.input.turn_detection v0.7b 寫死舊位置 OpenAI 回 Unknown parameter session.turn_detection

**Layer 3**: voice 從 session top-level 搬到 session.audio.output.voice marin 聲音沒套用

**配合 issue 次要**:
- 沒 explicit peerConn.addTransceiver audio direction sendrecv 依賴 addTrack 預設
- audio element 沒 playsinline attribute iOS Safari inline audio 政策
- ontrack callback srcObject 之後沒 explicit play autoplay policy 偶爾 block

### 1.3 Patch Diff 摘要

**index.html — audio element 加 playsinline**:
```
- <audio class="live-audio" id="liveAudio" autoplay></audio>
+ <audio class="live-audio" id="liveAudio" autoplay playsinline></audio>
```

**index.html JS — peerConn 加 transceiver + ontrack 加 explicit play**:
```javascript
peerConn.addTransceiver("audio", { direction: "sendrecv" });

peerConn.ontrack = function (ev) {
  if (ev.track.kind === "audio") {
    liveAudio.srcObject = ev.streams[0];
    var pp = liveAudio.play();
    pp.catch(function(err) { showError("音訊播放被擋"); });
  }
};
```

**index.html JS — session.update 對齊 GA v1 schema**:
```javascript
dc.send(JSON.stringify({
  type: "session.update",
  session: {
    type: "realtime",
    instructions: instructions,
    audio: {
      input: {
        transcription: { model: "whisper-1" },
        turn_detection: {
          type: "server_vad",
          threshold: 0.5,
          prefix_padding_ms: 300,
          silence_duration_ms: 800,
          create_response: true
        }
      },
      output: { voice: "marin" }
    }
  }
}));
```

**sw.js — cache version bump v0.7.0 -> v0.7.1c** 清舊 SW 必要
