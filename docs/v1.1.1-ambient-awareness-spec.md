## 📋 落地三段

### A · 時間感知強化（升級 v0.9.0.3 招呼語池）

**現況**：5 時段 × 5 句 = 25 句池、隨機撈。
**問題**：撈到「早安」但其實是星期一早 9 點 vs 星期六早 9 點意義完全不同；蘇菲沒分辨。

**v1.1.1 升級**：

```js
// castle/static/index.html 內 pickGreeting() 升級
function pickGreeting(ctx) {
  // ctx = { lastVisit: Date | null, isReturnSession: boolean, totalSessions: int }
  var now = new Date();
  var h = now.getHours();
  var day = now.getDay();  // 0 = Sun, 6 = Sat
  var isWeekend = (day === 0 || day === 6);
  var isMonday = (day === 1);

  // 三層 fallback：
  // 1. 接續 session（< 30 min 上次互動）→ 接話模式
  // 2. 同日重訪（< 24h）→ 短招呼
  // 3. 跨日 / 首訪 → 完整 25 句池

  if (ctx.lastVisit) {
    var gap = (now - ctx.lastVisit) / 1000 / 60; // minutes
    if (gap < 30) return pickContinuation(ctx);
    if (gap < 60 * 24) return pickShortHello(h, isWeekend);
  }

  return pickFullGreeting(h, isWeekend, isMonday);
}
```

**新增 3 個 sub-pool**：

| Sub-pool | 觸發 | 範例 |
|---|---|---|
| `pickContinuation()` | 同 session 30min 內回來 | 「Edward 回來了 · 我還在」「剛剛那個事還在你心上嗎」 |
| `pickShortHello()` | 同日重訪 | 「Edward 又上線了」「中午過後嗎」 |
| `pickFullGreeting()` | 跨日 / 首訪 | 維持原 25 句但加 isWeekend / isMonday 分支 |

**新增星期感知層**：
- 星期一早上 → 「Edward 早 · 新的一週」（不是普通早安）
- 週末 → 「Edward 週末嗎 · 不打擾」
- 星期五晚 → 「週末來了 · 你可以喘一下」

### B · 歷史感知（lastVisit + sessionCount 寫 localStorage）

**新增 `castle/static/session-memory.js`** （~80 行）：

```js
// 不依賴後端 / 不存對話內容 · 只存「時間戳 + session count + last greeting」
const SESSION_KEY = 'sophie_session_v1';

export function readSessionMemory() {
  try {
    const raw = localStorage.getItem(SESSION_KEY);
    if (!raw) return { lastVisit: null, totalSessions: 0, lastGreeting: null };
    const parsed = JSON.parse(raw);
    parsed.lastVisit = parsed.lastVisit ? new Date(parsed.lastVisit) : null;
    return parsed;
  } catch (e) {
    return { lastVisit: null, totalSessions: 0, lastGreeting: null };
  }
}

export function writeSessionMemory(greeting) {
  const now = new Date();
  const prev = readSessionMemory();
  const data = {
    lastVisit: now.toISOString(),
    totalSessions: (prev.totalSessions || 0) + 1,
    lastGreeting: greeting,
  };
  localStorage.setItem(SESSION_KEY, JSON.stringify(data));
}
```

**整合 index.html**：
- Start 按鈕 click → `ctx = readSessionMemory()` → `pickGreeting(ctx)` → 蘇菲講第一句
- 講完招呼 → `writeSessionMemory(greeting)` 寫回

**隱私**：
- localStorage 是 browser-side · 蘇菲後端不知道
- 不存對話內容、不存音訊、不存個資
- Edward 清瀏覽器 cookie / localStorage → 全清掉、隔天重新「首訪」
- 跨裝置不同步（一個 axis 而已、IndexedDB 跨裝置存留 v1.1.2 再做）

### C · 環境感知（visibility + tab focus + 時段微調）

```js
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    idleRotator.pause();  // 不浪費 CPU 動畫切換
  } else {
    idleRotator.resume();
    if (inCall) {
      // 通話中切回 = 沒中斷、不打擾
    } else {
      // 待機切回 = 蘇菲 micro-greet
      maybeEmitAnimation('acknowledgement');  // 12% 機率輕點頭
    }
  }

```

**時段微調動畫機率**：
- 深夜（>22:00）→ idle rotator interval 拉長到 12s（不要太活蹦）
- 早上（5-9）→ idle rotator interval 縮短到 6s（活力一點）
- 中午（12-14）→ 12% playful 機率（午後輕鬆）
- 晚上工作時段（18-22）→ 5% acknowledgement 機率（陪伴感）
