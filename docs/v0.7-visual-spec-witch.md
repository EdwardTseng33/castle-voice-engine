## § 1 · 5 階段視覺切換 spec（state machine · HTML + CSS + 過渡）

### 1.1 State machine 定義

```js
const STATES = {
  HIBERNATE:   'hibernate',    // 完全休眠 · GPU off
  WAKING:      'waking',       // 喚醒中 · GPU 啟動 5-8 秒
  PRE_CALL:    'pre-call',     // 通話前 · 真人視訊 idle 揮手
  IN_CALL:     'in-call',      // 對話進行中
  SOFT_PROMPT: 'soft-prompt',  // 軟降提示
  SEMI_IDLE:   'semi-idle',    // 半待機 · GPU 暫停
};
```

DOM root 用 `data-state` attribute 切換、所有階段差異透過 CSS attribute selector 實作（非 class list、避免 stale class）。

### 1.3 各階段觸發條件 + 過渡

| 階段 | 觸發進入 | 過渡（出 → 入） | 觸發離開 | GPU 狀態 |
|---|---|---|---|---|
| **hibernate** | 啟動 / semi-idle 後 5 分鐘無喚醒 | portrait fade-in 400ms | 喚醒詞 + 聲紋 OR 鏡頭偵測有人 ≥ 3 秒 | 容器 scaledown · $0 |
| **waking** | hibernate 觸發喚醒 | portrait + spinner fade-in 280ms（spinner overlay 在照片上） | 後台 `/voice/wake` ready event | GPU 啟動中 5-8 秒 |
| **pre-call** | waking ready event | portrait fade-out 400ms + live-video fade-in 400ms · cross-fade | 用戶點綠鈕 + permission 通過 | GPU 100% · idle 揮手 |
| **in-call** | start click + mic granted | start 鈕 hide + 3 圓鈕 fade-in 280ms + timer fade-in 280ms | 30 秒無對話 OR 點 end 鈕 | GPU 100% |
| **soft-prompt** | in-call · 無對話 30 秒 | soft-caption fade-in 400ms（其他不變） | 用戶開麥 OR 60 秒 + 鏡頭無人 → semi-idle | GPU 100%（防誤判） |
| **semi-idle** | soft-prompt · 60 秒 + 鏡頭無人 | live-video fade-out 400ms + portrait fade-in 400ms · cross-fade | 用戶點 OR 喚醒詞 → pre-call · OR 5 分鐘後 → hibernate | GPU 暫停（callObject.leave） |

**過渡實作 contract**（給卡西法 implement 參照）：
1. State change = JS 改 `shell.dataset.state = newState`
2. CSS attribute selector 自動切換 opacity + display
3. 同階段內的子元素過渡（timer / spinner）用 CSS transition 不用 JS
4. **不用 setTimeout chain**：用 `transitionend` event 確保 cross-fade 接力正確
5. 過渡途中不接受新 state change（race condition 鎖）

### 2.3 PIP 啟動 hook

```js
async function enterPIP() {
  const video = document.getElementById('liveVideo');
  if (!document.pictureInPictureEnabled) {
    log('此瀏覽器不支援 PIP');
    return;
  }
  try {
    if (document.pictureInPictureElement) {
      await document.exitPictureInPicture();
    } else {
      await video.requestPictureInPicture();
    }
  } catch (e) {
    log('PIP 啟動失敗: ' + e.message);
  }
}

video.addEventListener('leavepictureinpicture', () => {
  log('PIP closed, back to main');
});
```

### 3.3 `castle/static/sw.js`（Service Worker）

```js
// castle/static/sw.js
const CACHE_VERSION = 'v0.7.0';
const CACHE_NAME = `sophie-${CACHE_VERSION}`;

const SHELL_ASSETS = [
  '/static/index.html',
  '/static/sophie-portrait.png',
  '/static/icon-192.png',
  '/static/icon-512.png',
  '/static/manifest.json',
  'https://unpkg.com/@daily-co/daily-js'
];

const NEVER_CACHE = [
  '/tavus/', '/voice/', '/realtime/', '/breeze/', '/health'
];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(SHELL_ASSETS))
  );
  self.skipWaiting();
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(
        keys.filter((k) => k.startsWith('sophie-') && k !== CACHE_NAME)
            .map((k) => caches.delete(k))
      )
    )
  );
  self.clients.claim();
});

self.addEventListener('fetch', (event) => {
  const url = new URL(event.request.url);

  if (NEVER_CACHE.some((p) => url.pathname.startsWith(p))) {
    event.respondWith(fetch(event.request));
    return;
  }

  if (event.request.method === 'GET' &&
      (SHELL_ASSETS.includes(url.pathname) || url.origin === 'https://unpkg.com')) {
    event.respondWith(
      caches.match(event.request).then((cached) => {
        return cached || fetch(event.request).then((resp) => {
          if (resp.ok) {
            const clone = resp.clone();
            caches.open(CACHE_NAME).then((c) => c.put(event.request, clone));
          }
          return resp;
        });
      })
    );
    return;
  }

  event.respondWith(
    fetch(event.request).catch(() => caches.match(event.request))
  );
});
```

`index.html` 內註冊：
```js
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/static/sw.js', { scope: '/static/' });
}
```
