## v1.7.3 · Slack / Gmail 漏接提醒

### Slack（最簡 · 用 webhook）

Edward 動 3 步：
1. https://api.slack.com/apps → Create New App → From scratch → 命名「Sophie」+ 選 workspace
2. Incoming Webhooks → Activate → Add New Webhook to Workspace → 選你的個人 channel（譬如 #me 或 DM）→ 拿 Webhook URL
3. Modal Secret 加：
   ```bash
   modal secret create slack-webhook SOPHIE_SLACK_WEBHOOK_URL=https://hooks.slack.com/...
   ```

蘇菲後端可動 → 我加：
- `attach_secrets` 加 `slack-webhook` secret
- `/brain/notify_slack` endpoint · POST Slack webhook URL
- 後端 cron 監測未讀（需 Slack Bot Token 才能讀訊息 · 暫時不接讀只接寫）

**MVP 範圍**：蘇菲能「主動 push 訊息給 Edward 的 Slack」（不能讀別人發的、那要 Bot Token）

### Gmail（OAuth · 比較複雜）

Edward 動 4 步：
1. https://console.cloud.google.com/apis/library → 啟用 Gmail API
2. https://console.cloud.google.com/apis/credentials → 加 OAuth Client（同你 Google 登入用的、加 Scope `gmail.readonly`）
3. 用 Google OAuth Playground 取 refresh_token
4. Modal Secret 加：
   ```bash
   modal secret create gmail-oauth \
     GMAIL_CLIENT_ID=xxx GMAIL_CLIENT_SECRET=xxx GMAIL_REFRESH_TOKEN=xxx
   ```

蘇菲後端可動 → 我加：
- `/brain/gmail_unread_count` endpoint
- 定時拉未讀 + Claude 判斷哪封重要 + push Slack 提醒 Edward

## v1.7.4 · Google 日曆讀寫

Edward 動 4 步：
1. https://console.cloud.google.com/apis/library → 啟用 Google Calendar API
2. 同 v1.7.3 Gmail 流程、加 Scope `calendar.events`（讀寫日曆）
3. 用 OAuth Playground 取 refresh_token
4. Modal Secret 加：
   ```bash
   modal secret create calendar-oauth \
     CALENDAR_CLIENT_ID=xxx CALENDAR_CLIENT_SECRET=xxx CALENDAR_REFRESH_TOKEN=xxx
   ```

蘇菲後端可動 → 我加：
- `/brain/calendar_today` endpoint · 拿今天 events
- `/brain/calendar_create` endpoint · 創建新 event
- `/brain/calendar_update` endpoint · 改 event
- session.update tools 加：`get_calendar_today` / `create_calendar_event` / `update_calendar_event`
- 蘇菲講「明天 3 點安排會議」就能真排
