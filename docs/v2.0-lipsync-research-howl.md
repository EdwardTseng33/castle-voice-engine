## 真人版蘇菲（終局繞不開）

所有 AI-only 方案根本問題沒解：訓練資料若是 AI 生成 = AI 教 AI = 不跨真實感門檻。

### 成本估算（台灣場景）

| 項目 | 預估 |
|---|---|
| 演員 talent fee（拍 2-3 hr / 30 分鐘成品） | NT$ 8,000-15,000 |
| 攝影 + 燈光（半天 studio） | NT$ 5,000-10,000 |
| 後製剪輯 + 字幕 | NT$ 3,000-5,000 |
| 場地 | NT$ 2,000-5,000 |
| **總計** | **NT$ 18,000-35,000（USD $580-1,130）** |

### 場景準備

1. 光線：自然光 + 補光 + softbox · 避免 harsh shadow
2. 背景：純色 / 弱景深
3. 服裝：2-3 套避免 overfit
4. 中文發音腳本：對話日常 30% + 報告語境 40% + 情緒語境 30%
5. 表情：認真 / 微笑 / 思考 / 同理 4 種底面 × 5-7 分鐘
6. 量：30 分鐘 raw 是底線、45-60 分鐘更安全

### 演員選擇 hard rule

「氣質符合蘇菲人設」> 漂亮。樸實 / 內在豐富 / 不矯飾。

### 法律準備

合約必含：
- 肖像權永久授權給 AI fine-tune 用途
- 對外分身使用同意書
- sulima 先擬模板

## 城堡內部對齊

### ADR-020 Track A 個人自用 GO 範圍

LatentSync 1.6 = ByteDance 國籍 → Track A 個人自用 + 本機 inference / fine-tune = **大概率 sulima Tier B audit GO**
- 條件：訓練資料不上 cloud + inference 本機跑 + 不對外服務
- 若未來 v2.0 對外（Voice Path 訪談分身 v0.5+）= 要重跑 Tier C audit

### sulima Tier B audit 觸發

- ✅ Edward 拍板「v2.0 路徑就走 LatentSync」之後（不是現在）
- PoC 前 1-2 週派、不要 PoC 跑一半補

audit 4 條重點：
1. ByteDance model weights download + license 字面確認
2. Fine-tune data 本機落地路徑（不外洩）
3. Inference output 不送 ByteDance cloud
4. 若未來對外服務 = 重新 Tier C audit
