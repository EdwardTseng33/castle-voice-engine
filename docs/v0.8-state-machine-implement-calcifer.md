## § 2. animation-pool.js 新檔 spec

148 行 · ES5 strict mode IIFE · 對外暴露 `window.AnimationPool` constructor + `window.ANIMATION_POOL_STATES`：
- ctor `new AnimationPool(videoEl)` = 預設 idle autoplay loop muted · preload 3 個 action mp4 (hidden video element primer)
- `playAction(state)` = 切 src 至 action mp4 + loop=false + 一次性 onended 自動 `_returnToIdle()`
- `_returnToIdle()` = 切回 sophie-idle.mp4 + loop=true · 移除 onended handler 避免疊加
- 缺的狀態（thinking / happy / impressed / yawn）= silent fallback log + 留在 idle 不報錯

## § 3. GPT session.update tools 段

session.update payload 末加 `tools: [{ type: "function", name: "emit_animation_state", parameters: { state: enum["speaking","task-received","task-handoff"] }}]` + instructions 末尾串 `animDirective` 教 GPT 何時呼叫 · 用 `\n` escape single-line literal（不能跨行 · 已驗 node --check pass）。
