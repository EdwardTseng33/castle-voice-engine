## Edward 要的（願景）

蘇菲不只是「聽 + 說 + 瞄一眼」，而是**真正的雙向視訊夥伴**：
1. **看懂 Edward 的動作 / 手勢**（揮手、比讚、指東西、招手）
2. **看懂表情**（笑、累、皺眉、驚訝）
3. **用手 / 表情跟 Edward 互動**（Edward 揮手 → 蘇菲揮手回；比讚 → 蘇菲開心；Edward 累 → 蘇菲關心）
4. 整體 = 像兩個人在視訊、有肢體 + 表情的來回，不只是語音

## 缺口（要做的）

1. **手勢偵測沒接到即時前端 + 沒餵給蘇菲理解**（pose_hands 在後端、但雲端沒鏡頭、要改成前端 MediaPipe 跑）
2. **表情偵測淺**（要從「emotion state」升級到「蘇菲真的看懂 + 講出來 + 反應」）
3. **蘇菲的反應沒跟 Edward 的動作對上**（她有 13 動畫、但沒「你揮手我揮手回」這種對應觸發）
4. **視覺看不深**（穿什麼、手比什麼 → 要 on-demand 詳細看，今天發現的限制）

## 分階段（每階段可獨立驗 + 體感升級）

| 階段 | 做什麼 | 體感 |
|---|---|---|
| **A · 視覺看得深**（先做、1-2 hr） | on-demand 詳細看：Edward 問「我穿什麼 / 手比什麼」→ 蘇菲當下抓畫面 + 帶問題問 Claude + 答 | 「她真的看懂我」 |
| **B · 手勢偵測上前端**（半天） | 前端 MediaPipe 跑手/姿勢 · 偵到揮手 / 比讚 / 招手 → 餵蘇菲 | 「她知道我在比什麼」 |
| **C · 雙向反應對應**（半天） | Edward 揮手 → 蘇菲 greeting 揮手回；比讚 → happy；累 → 關心。動作對動作 | 「我們在互動」 |
| **D · 表情即時同步**（半天） | Edward 表情變 → 蘇菲表情跟著回（笑對笑、皺眉關心） | 「她有在看我的臉」 |

**先後**：A（看得深）最有感 + 最快、先做。B/C/D 是「肢體雙向」、依賴前端手勢偵測（要先把 MediaPipe 搬到前端跑、因為雲端沒鏡頭 — 這是今天才釐清的關鍵）。

## 真實限制（誠實）

- **雲端沒實體鏡頭**：所有「看」必須前端抓畫面送上去（今天的 /vision/analyze_now 已是這架構）。手勢偵測也要前端 MediaPipe 跑、不能靠後端 cv2（今天確認 `/camera/enable` 後端 503 就是這原因）。
- **成本**：on-demand 詳細看每次約 NT$ 0.3 · 手勢偵測前端跑（免費）· 在預算內。
- **延遲**：Claude 視覺 1-2 秒（看得深可接受）· 手勢偵測前端即時（快）。
