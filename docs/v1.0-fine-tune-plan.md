### B · fine-tune dataset 準備

**option 1 · MuseTalk fine-tune（推薦）**：

- 跳過 fine-tune、直接每句 TTS audio → MuseTalk inference 嘴對齊 mp4

- 缺點：嘴型還是「通用 MuseTalk」、不夠像蘇菲

**蘇菲 council 推薦 option 1**：差異化體驗值 $30-40。但 option 1 需要說真話、ground truth：100 句的「真實人類嘴型」其實沒有（vivago.ai 是 AI 生成、不算 ground truth）。所以實際上 option 1 是「半監督」、效果不保證大幅優於 option 2。

**蘇菲 council 重新評估**：先跑 option 2 全 100 句、看效果、若 Edward 覺得「夠好了」就 stop · 省 $30-40 + 6-10 hr GPU 時間。若覺得不夠像蘇菲再升 option 1。

### C · 預生 mp4 自動化 + 動態切換

**新增 `castle/pregenerated/` 資料夾**：
- `phrase_001.mp4`（「早安 Edward · 新的一天從這裡開始」）
- `phrase_002.mp4`
- ...
- `phrase_100.mp4`
- `manifest.json`（句子 → mp4 對照 + transcript + duration）

**新增 `castle/static/phrase-matcher.js`**（~120 行）：
```js
// GPT realtime 講話前先 trigger response.text.delta · 蘇菲拿到完整 transcript chunk
// fuzzy match (Levenshtein < 0.2 distance) → 找 phrase_XXX.mp4
// 找到 → 切預生 mp4 (currentTime sync)
// 找不到 → fallback 17 動畫池 (v0.8-v1.1.3 邏輯)

const PHRASE_MAP = await fetch('/static/pregenerated/manifest.json').then(r => r.json());

export function findMatchingPhrase(text) {
  const normalized = text.replace(/[、，。！？]/g, '').trim();
  for (const entry of PHRASE_MAP.phrases) {
    if (levenshtein(normalized, entry.transcript) / entry.transcript.length < 0.2) {
      return entry; // { mp4: "phrase_023.mp4", duration: 2.8, transcript: "..." }
    }
  }
  return null;
}
```

**整合 `index.html`**：
- GPT realtime response.text.delta event listener
- 累積 text 到段落結束 → findMatchingPhrase(text)
- match → 切 `phrase_XXX.mp4` 同步 audio
- miss → fallback 動畫池
