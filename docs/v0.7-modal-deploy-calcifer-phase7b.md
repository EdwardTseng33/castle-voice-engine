## Section 9 - Lessons learned

1. **Gate 5 (read official docs first) saved us** - Phase 7b opened with curl Sonic README + requirements.txt, decided license + dep double-block NO-GO within 30 min, zero Modal compute. Best example of feedback (integrating third-party tool step 1 = read official docs first).

2. **chrome MCP video render limit real (Phase 7a lesson 4 reproduced)** - Even with 206 Partial Content + Accept-Ranges + 500K mp4 fully OK on server, chrome MCP env video element stuck at readyState=0. Real Chrome / Edge / Safari works. Demo URL to Edward must be tested in regular browser.

3. **Downgrade more honest than fake realtime** - MuseTalk batch 10x realtime delay unavoidable. Fake realtime = why no movement complaint. Downgrade + watermark = honest. Castle value = whole delivery not piecemeal.

4. **License is license not technical issue** - Even with dep + GPU resolved, CC BY-NC-SA-4.0 disallows commercial = self-host Sonic forever NO-GO for Voice Path. License gate first, technical eval second.

5. **MuseTalk WS endpoint kept (not used in 7b)** - Independent Modal app, no impact on castle main. Phase 7c Path A will use it. Removing musetalk_client.py = removing wiring + sulima audit C12 subject_guard integration.

6. **Downgrade is expectation setting not tech debt** - Watermark explicit (visual placeholder, Phase 7c pending real streaming). Edward will not misjudge. More honest than fake.
