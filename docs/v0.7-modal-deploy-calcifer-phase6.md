## Section 10 - Lessons learned

1. MuseTalk official download_weights.sh is broken on Modal US - root cause was export HF_ENDPOINT=https://hf-mirror.com on line 18 (China mirror, blocked from Modal datacenters). Future MuseTalk forks should patch line 18 OR replace script with HF native Python API.

2. HuggingFace CLI silent-fail on partial downloads is recurring anti-pattern - third tool this month after SoulX-FlashHead 5/22 + Duix 5/22. Default to Python snapshot_download over huggingface-cli when scripting inside Modal containers.

3. gdown v5+ broke --id flag - MuseTalk official script still uses old form. Action: extend feedback_third_party_tool_official_docs_first.md gate with Gate 5 check upstream tool CLI version compat.

4. Lazy loading optional components saves cold start - Sophie landmark caching is nice-to-have, blocking @modal.enter() on heavy import (mmpose) was wrong. Pattern: optional features try/except ModuleNotFoundError.

5. Modal app stop -y then redeploy breaks out of crash-loop - once function crash-loops, Modal backoff means new deploys still land on dying containers. Force-stop clears state cleanly.
