## § 1. 設計哲學

跟遊戲動畫 state machine 完全一致：
```
idle (永遠在跑) ──┐
                 │
   trigger event│
                 │
                 ▼
            action loop (5s · 首偵=尾偵=idle 第 1 偵)
                 │
                 │ 自動接回
                 ▼
            idle (繼續永遠跑)
```

無縫接回 = idle 第 1 偵 + 每個 action 的首偵 + 每個 action 的尾偵 = **三者像素級一致**。

## § 2. 7 個狀態（含 idle base）

| 狀態 | 觸發來源 | 情緒描述 |
|---|---|---|
| **idle** | 預設、永遠跑 | 待機微笑看鏡頭 |
| **task-received** | 用戶剛講完話、GPT 開始處理 | 收到、了解、點頭 |
| **thinking** | GPT token generation 中 + 對話含「為什麼/怎麼辦」 | 思考、眼神望斜上方 |
| **happy** | GPT 回答含正向詞 + 用戶笑（鏡頭偵測）| 高興、笑容開、小聳肩 |
| **impressed** | 用戶分享成就（「搞定/簽到了」）| 崇拜、wow 表情 |
| **yawn** | 深夜時段（22:00+ TST）OR 用戶說「累了」OR 鏡頭偵測疲態 | 打哈欠、累但還在 |
| **task-handoff** | 對話結束 + 含「OK 動 / 就這樣」 | 接住、自信點頭 |

## § 4. 觸發機制設計（3 層）

### 4.1 GPT Realtime function calling（主路）

`castle/server/realtime_endpoints.py` session.update 加 tools array：

```json
{
  "type": "session.update",
  "session": {
    "type": "realtime",
    "tools": [
      {
        "type": "function",
        "name": "emit_animation_state",
        "description": "Trigger Sophie avatar to play a specific emotion/action loop. Called inline with speech.",
        "parameters": {
          "type": "object",
          "properties": {
            "state": {
              "type": "string",
              "enum": ["task-received", "thinking", "happy", "impressed", "yawn", "task-handoff"],
              "description": "The animation state to play. Returns to idle automatically."
            }
          },
          "required": ["state"]
        }
      }
    ],
    "instructions": "When responding, emit emit_animation_state(state) inline based on emotional content..."
  }
}
```

GPT realtime 講話時自己 emit、瀏覽器收到 → 切換 video。

### 4.2 Browser JS state machine（接收 + 切換）

`castle/static/animation-pool.js` 新檔：

```javascript
const ANIMATION_POOL = {
  'idle': '/static/sophie-poc-loop.mp4',
  'task-received': '/static/sophie-task-received.mp4',
  'thinking': '/static/sophie-thinking.mp4',
  'happy': '/static/sophie-happy.mp4',
  'impressed': '/static/sophie-impressed.mp4',
  'yawn': '/static/sophie-yawn.mp4',
  'task-handoff': '/static/sophie-task-handoff.mp4',
};

class AnimationPool {
  constructor(videoEl) {
    this.video = videoEl;
    this.currentState = 'idle';
    this.preloadCache = new Map();
    this.preloadAll();
  }

  async preloadAll() {
    for (const [state, src] of Object.entries(ANIMATION_POOL)) {
      const preloader = new Video();
      preloader.src = src;
      preloader.preload = 'auto';
      this.preloadCache.set(state, preloader);
    }
  }

  // 觸發單次 action loop，跑完自動回 idle
  async playAction(state) {
    if (!ANIMATION_POOL[state]) return;
    if (state === 'idle') return; // idle 永遠跑、不必觸發

    // 等當前 loop 跑到尾偵（first frame = last frame = idle 第 1 偵）
    await this.waitForLoopBoundary();

    // 切換 src 到 action mp4
    this.video.src = ANIMATION_POOL[state];
    this.video.loop = false; // action 只跑一次
    this.video.play();
    this.currentState = state;

    // 動畫結束自動回 idle
    this.video.onended = () => {
      this.video.src = ANIMATION_POOL['idle'];
      this.video.loop = true;
      this.video.play();
      this.currentState = 'idle';
    };
  }

  waitForLoopBoundary() {
    // 算當前 video time 距尾偵還多少
    return new Promise(resolve => {
      const remaining = this.video.duration - this.video.currentTime;
      setTimeout(resolve, remaining * 1000);
    });
  }
}
```

## § 6. 首偵 = 尾偵 driver 紀律（無縫接回 idle）

每支動畫 mp4 必過 3 道 check 才能納入 pool：

1. **像素比對**：抽 frame 0 + frame 119（5 秒 24fps 最後 1 偵）+ idle 第 1 偵 = 三者 SSIM ≥ 0.97（結構相似度近完美）
2. **眼睛位置**：landmark 3 個關鍵點（左眼 / 右眼 / 鼻尖）位置誤差 ≤ 5 px
3. **嘴形**：嘴角位置誤差 ≤ 3 px、開口度差距 ≤ 0.05

不過 check = 用 OpenCV 自動偵測接縫 + 給 Edward 回饋 prompt 哪裡要調（例：「結尾 frame 120 嘴張開 0.12 > idle 0.05 = mouth not fully closed」→ Edward 加強 prompt「end with closed mouth soft smile」重生）。
