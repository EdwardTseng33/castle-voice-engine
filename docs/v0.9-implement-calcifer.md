## v0.9.3 - 視訊雙向情感同步 (FaceMesh-only · Pose/Hands deferred per stop-loss)

**架構決策**: 既有 castle/multimodal/ + castle/server/ 用 HTTP polling 模式
(browser poll /vision/latest)·不走 spec 原 dataChannel relay 路徑·
避免動 castle/server/realtime_endpoints.py (對齊不衝清單)。
**Route B**: 加 /vision/emotion_latest endpoint + browser 1Hz poll 直送 animPool.playAction()

**Pose / Hands**: 砍 (對齊 stop-loss · dep hell 風險). FaceMesh-only ship 4 emotion + 0 pose + 0 hand gesture. 預留 hook v0.9.4 補。

### File 1: castle/multimodal/camera.py  (+108 lines · 304 -> 412)

- keypoint_idx 擴 8 -> 18 (覆蓋 eye corners / eye openness / nose / mouth corners / lip top-bot / chin / forehead / brow)
- detect_emotion(self) method 新加: FaceMesh-based 4 emotion classifier
  - acknowledgement (mouth_aspect > 0.55 + ear_avg > 0.35 · 驚訝張嘴)
  - apologetic (corner_offset > 0.012 + brow_gap < 0.045 · 嘴角下垂 + 皺眉)
  - happy (corner_offset < -0.010 + mouth_h > 0.060 · 嘴角上揚 + 笑寬)
  - resigned (ear_avg < 0.18 + |corner_offset| < 0.005 · 眼半閉 + 中性嘴)
- get_emotion_event(self) method 新加: 15s per-state cooldown · confidence >= 0.7 才 emit
- 隱私守則無動 (subject_guard / kill switch / no disk write 全保)

**Syntax check**: py_compile PASS
