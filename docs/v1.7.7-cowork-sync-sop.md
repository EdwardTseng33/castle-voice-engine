## 共用記事本架構

Voice Path 後端已 ship 3 個接口 (v1.7.1)、跨裝置寫讀同一份雲端硬碟：

| 接口 | 用途 |
|---|---|
| `POST /memory/shared/set` `{key, value}` | 寫一筆紀錄 |
| `GET /memory/shared/get/{key}` | 讀一筆紀錄 |
| `GET /memory/shared/list` | 列所有 keys |

### 方法 B · Python httpx

```python
import httpx
from itsdangerous import URLSafeTimedSerializer

s = URLSafeTimedSerializer(
    'a7f9c2e4d8b1a3c5e7f0b2d4a6c8e1b3d5f7a9c2e4b6d8f0a2c4e6b8d1f3a5c7',
    salt='sophie-auth-cookie-v1'
)
cookie = s.dumps('edwardt0303@gmail.com')

base = "https://edwardt0303--castle-voice-engine-fastapi-app.modal.run"
headers = {"Cookie": f"sophie_auth={cookie}"}

# 寫
r = httpx.post(
    f"{base}/memory/shared/set",
    headers={**headers, "Content-Type": "application/json"},
    json={"key": "work_status", "value": {
        "status_summary": "BeyondPath 收尾 / Voice Path v1.7.2 ship / HirePath 等 PRD",
        "projects": [
            {"name": "BeyondPath", "version": "v1.5", "status": "收尾"},
            {"name": "Voice Path", "version": "v1.7.2", "status": "ship"},
            {"name": "HirePath", "version": "v0.1", "status": "等 PRD"},
        ],
    }},
)
print(r.json())

# 讀
r = httpx.get(f"{base}/memory/shared/get/work_status", headers=headers)
print(r.json())
```

## 跨裝置同步觸發場景

### Cowork → Voice
- Cowork 端 ship 完一個版本 → Cowork Claude 主動寫 work_status
- 譬如 ship v1.7.2 後、Cowork Claude 跑：
  `httpx.post("/memory/shared/set", json={"key": "work_status", "value": {...}})`
- Voice Path 蘇菲下次開機就讀到、晨間 brief 自動帶最新進展

### Voice → Cowork
- Edward 跟 Voice Path 蘇菲講「我這週末打算去吃牛角燒肉」→ Voice 蘇菲寫進 `shared_user_plans`
- Cowork Claude 開新 session → 讀 `shared_user_plans` 知道 Edward 計畫
- 不必 Edward 再重複講

## 推薦 keys 結構

| key | value 結構 |
|---|---|
| `work_status` | `{status_summary, projects: [{name, version, status}], last_updated}` |
| `user_plans` | `{plans: [{when, what, where}], last_updated}` |
| `user_preferences` | `{likes, dislikes, dietary, hobbies, recent_interests}` |
| `last_booking` | `{restaurant, when, party_size, google_search}` (Voice Path v1.7.5 自動寫) |
| `recent_conversations` | `{voice_summary, cowork_summary, last_updated}` |

## 安全考量

- Cookie secret 是公開 hardcoded fallback (在 Voice Path repo 也看得到)
- 所有寫入會經過 Modal 後端、沒人能繞過接口直寫 Volume
- key 防 path traversal (只接 alphanumeric + `_-`)
- 不存 PII / 信用卡 / 密碼這類敏感資料 (Sally 紅線守住)
