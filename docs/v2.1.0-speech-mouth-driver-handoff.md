# v2.1.0 Speech Mouth Driver Handoff

Date: 2026-05-25
Owner: Howl / Codex

## Product Decision

Edward clarified that the near-term goal is not exact word-for-word lipsync. The goal is a natural speaking impression on top of idle animation 1-4:

- idle body animation remains active
- mouth moves only while Sophie is speaking
- mouth movement follows audio / word cadence
- no `sophie-speaking.mp4` loop as the default speaking state
- no generic lipsync video swap as the default normal dialogue path

## Changed Files

- `castle/static/index.html`
- `castle/static/animation-pool.js`

## Behavior

- Default normal dialogue uses `speech_mouth=1`.
- Default exact phrase lipsync is now opt-in with `?lipsync=1`.
- Default generic lipsync fallback is now opt-in with `?lipsync_fallback=1`.
- The mouth driver sits above the idle video and is driven by:
  - remote audio energy from `window.__sophieRemoteAudioAmp`
  - realtime transcript deltas via `pulseSpeechMouth(delta)`
- Silence and punctuation reduce mouth opening; audio/text pulses open it.

## Test URL

`/static/index.html?speech_mouth_test=1&cache_bust=v210`

Expected:

- `liveVideo` remains an idle video, not `/static/sophie-speaking.mp4`
- `liveVideoSpeaking` stays hidden
- `#sophieMouthDriver` becomes visible and pulses for 10 seconds
- ready log: `Voice Path v2.1.0 ready - speech mouth driver on idle base - 2026-05-25`

## Honest Limitation

This is not true phoneme lipsync. It is word/audio cadence mouth motion. It should feel much more natural than a constant talking loop, but exact mouth shape still requires a future compositor or generated mouth track.
