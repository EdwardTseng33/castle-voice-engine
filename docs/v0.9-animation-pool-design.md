## § 3 · 接縫紀律（自然感關鍵）

### 3.1 隨機回 idle 池

每支 action 跑完 = 不固定回同一支 idle、**隨機從 idle-1/2/3/4 挑一支**：

```js
class AnimationPool {
  playAction(state) {
    this.video.src = ANIMATION_POOL[state];
    this.video.loop = false;
    this.video.onended = () => {
      const nextIdle = this.idleRotator.next();
      this.video.src = ANIMATION_POOL[nextIdle];
      this.video.loop = true;
      this.video.play();
    };
  }
}
```

### 3.2 頻率防護

```js
class FrequencyGuard {
  constructor() { this.lastTrigger = {}; }
  
  canTrigger(state) {
    const now = Date.now();
    const COOLDOWN = {
      'happy': 30000,           // 30 秒不重複
      'acknowledgement': 30000,
      'apologetic': 60000,      // 道歉 60 秒不重複
      'resigned': 45000,
      'greeting': 600000,       // 打招呼 10 分鐘不重複
      'speaking': 0,            // 講話狀態無冷卻
      'speaking-with-gesture': 0,
    };
    const cool = COOLDOWN[state] || 0;
    const last = this.lastTrigger[state] || 0;
    if (now - last < cool) return false;
    this.lastTrigger[state] = now;
    return true;
  }
}
```

### 3.3 講話狀態保護 + 智能 loop + 呼吸節奏（Edward 5/23 17:25 拍板核心）

GPT 講話期間（response.audio.start ↔ response.audio.done）= 智能切換 speaking 變體：

**3.3.1 講話時長智能切換**（依 GPT 真實 audio event 動態觀察 · 不預估時長）

```js
class SpeakingController {
  start() {
    this.startMs = Date.now();
    // 階段 1: 0-5s 用「講話帶手部」一次播 (手勢不重複)
    this.play('speaking-with-gesture', { loop: false });
    
    // 5s 後若 GPT 還在講 → 切 階段 2
    this.t1 = setTimeout(() => this.enterPhase2(), 5000);
  }
  
  enterPhase2() {
    // 階段 2: 5-15s 切「講話基本」loop (嘴動 loop 違和低)
    this.play('speaking', { loop: true });
    
    // 15s 後若 GPT 還在講 → 啟動 階段 3 呼吸節奏
    this.t2 = setTimeout(() => this.enterPhase3(), 10000);
  }
  
  enterPhase3() {
    // 階段 3: > 15s 啟動「呼吸節奏」每 8s 講話基本 → 1.5s 待機 → 講話基本
    this.breathCycle = setInterval(() => this.breathePause(), 8000);
  }
  
  breathePause() {
    // 1.5 秒待機呼吸 (模擬真人「講 8 秒喘 1 秒」自然節奏)
    this.play(this.idleRotator.next(), { loop: false, duration: 1500 });
    setTimeout(() => {
      this.play('speaking', { loop: true });
    }, 1500);
  }
  
  stop() {
    // GPT 講完 = 立刻切 idle pool (不固定回哪支)
    clearTimeout(this.t1);
    clearTimeout(this.t2);
    clearInterval(this.breathCycle);
    this.play(this.idleRotator.next(), { loop: true });
  }
}

GPT_DC.on('response.audio.start', () => speakingCtrl.start());
GPT_DC.on('response.audio.done', () => speakingCtrl.stop());
```

**3.3.2 核心設計理念**

- 不預估講話時長（GPT realtime API 不提供）= 純粹動態觀察 + 階段升級
- 真人講話 8 秒自然換氣 = 1-1.5 秒嘴閉合「不是違和、是更自然」
- > 15 秒長段才啟用呼吸節奏（避免短段被打斷）
- 每次呼吸隨機從 idle-1/2/3/4 挑（畫面變化感）

**3.3.3 GPT 情緒中段切換例外**

GPT 講長段時自己 emit 情緒切換（例：講話中突然「對不起」）= 允許短暫 1.5 秒切 apologetic 後回 speaking。這層複雜、v0.9.1 先不上、v0.9.2 補。

### 4.7 頻率防護 + 紀律守則

- **15 秒 cooldown**：每個視訊觸發狀態 15 秒內不重複（避免你笑 → 蘇菲笑 → 你笑回應 → 蘇菲又笑無限循環）
- **講話狀態優先**：GPT 講話期間（response.audio.start ↔ done）= 視訊觸發 queue 起來不立刻切、講完才補
- **confidence ≥ 0.7**：MediaPipe + Claude vision 兩層判斷、雙層過 0.7 才觸發
- **Sally hard rule**：camera.py 既有 subject_guard 守、未成年偵測自動 disable 視訊
- **隱私 7 大類**（Phase 3 既有）：frame RAM-only / 不存磁碟 / kill switch ≤ 200ms / TLS
