## 三、4 條升分路線（按順序）

### v1.9 · 感知層補強（最先動 · 純嘴臉端）

**為何最先**：霍爾 verdict「最大短板、補完最有感」。蘇菲現在像個瞎眼助理、不知道你在不在、在做什麼。

4 種可靠訊號：

1. **你在不在電腦前**
   - 技術：瀏覽器 page visibility API + mic 活動偵測
   - 訊號：visible / hidden / mic_active / idle_30min

2. **你目前在哪個工作 app**
   - 技術：透過 dispatch_code 拉 Claude App 那邊 active window 狀態
   - 訊號：app_name (VS Code / Slack / Chrome / Figma)

3. **Slack / GitHub / Cowork 最近狀態**
   - 技術：Claude App MCP 拿 (Slack 未讀 / GitHub PR / Cowork task)
   - 訊號：unread_count / pending_pr / active_task

4. **你在通話 / 專注**
   - 技術：麥克風被佔用 = 通話 · 連續 30 分沒語音輸入 = 推測專注
   - 訊號：on_call / focused / break

**蘇菲應用**：
- 早上開蘇菲：「你 Slack 有 12 封未讀、3 個 PR 在等你、Cowork 那邊蘇菲昨晚 ship 了 v1.8.7 等你看」
- 中午：「你已經連續寫 code 2 小時、要不要起來走走」
- 晚上：「你 Slack 連 40 分沒動、應該是專注、我不打擾」

### v2.1 · 派工任務面板 UI（霍爾 verdict 必加）

**為何**：派工後端 2.5/3 但「使用者看不到她在管事」── 只能感覺、不能展示。升 3/3 必加 UI。

5 欄面板（蘇菲畫面右下浮一個小視窗）：

```
📋 待辦 (Pending)
🔄 進行中 (In Progress)
🚧 卡住 (Blocked)
✅ 完成 (Done · 今日)
🔁 交接 (Handoff to Cowork/Howl)
```

互動：
- 浮在右下角、可摺疊
- 你語音「蘇菲、你在管什麼」→ 口語播報 + 面板浮出
- 你關掉面板 → 蘇菲繼續安靜管、不吵

### v2.2 · dispatch_code 真實接通 Claude App

**為何**：你 Claude App MCP 全套接好（Slack/Gmail/Calendar/Notion/Figma）── 不該重複建 OAuth、應該派工過去用既有 MCP。

架構決定（5/24 拍板）：
- **手腳留在 Claude App（不搬）**：MCP 全套已成熟
- **嘴臉在 Voice Path 雲端**：OpenAI Realtime + Claude brain
- **嘴臉 → 大腦派工**：dispatch_code 真實 bridge

例外（Voice Path 必須自建）：
- ✅ Slack webhook（純 push · 24/7 主動 · 你電腦關機也能推）
- ✅ Recall.ai 進 Meet（你在會議現場、Voice Path 才在）
- ❌ Gmail / Calendar / Notion / Figma 讀寫 → 走 dispatch_code

之前 v1.7.3 / v1.7.4 「Voice Path 自建 Gmail/Calendar OAuth」計畫書 = 廢棄、不重做。

### v2.0 · 主動觸發少而準

**為何**：1.5 → 2.3 不靠「多」、靠「少而準」。霍爾原話：「重點不是多吵、是少而準」。

每日 2 次 briefing：
- 早 09:00：今日重點 (Calendar + Slack 未讀 + 卡住 PR + 你昨天承諾)
- 晚 21:00：今日 review + 明日 prep

4 種事件觸發：
- 任務逾時前 2 hr
- Slack / GitHub PR 對方 24 hr 沒回
- 你 4 hr 沒動工作（不打擾、純記錄）
- 你給的承諾沒兌現（昨天說「下午改 X」、結束沒做）

紀律：
- 每天最多 push 3 條（淹了就 mute）
- 每條附 1 個明確 action（不是純資訊）
- 你不回應 = 不催（不像 LINE bot 一直 ping）

### v2.3 · 紅線守護穩 + 語音情感變調（最後 · ROI 低）

- 紅線（不簽合約 / 不動錢 / 不洩 Sally）寫進每個工具 hard-coded 規則、不靠 prompt 自律
- 4 種情感變調：平穩 / 興奮 / 安撫 / 嚴肅 · 重跑 100 句嘴對齊 mp4（$40-50）
