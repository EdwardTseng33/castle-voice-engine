蘇菲語音 demo

castle-voice-engine v0.2.0 · gpt-realtime-2 · WebRTC
準備就緒。按上面的按鈕、開麥克風講中文。
怎麼用：
1. 按「開始對話」、瀏覽器會問你要不要開麥克風 → 允許
2. 等狀態變綠「連線完成、你講話蘇菲就會回」
3. 直接講中文。蘇菲會即時聽 + 即時回。
4. 想結束按「結束對話」。

注意：
• 建議用 Chrome / Edge / Firefox（Safari 也行但 WebRTC 有時不穩）
• 第一次連 Modal cold start 可能 3-5 秒
• 端到端延遲 500ms-1.5s（OpenAI Realtime spec）
• 廠商 voice = marin（溫暖中性女聲、最新 OpenAI Realtime 2026 voice）
